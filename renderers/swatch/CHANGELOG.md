# Changelog

## 0.1.0 (unreleased)

- Add a standalone Swatch Job renderer that displays solid color tiles labeled
  with `#rrggbb` for evaluating ARPRT palette conversion on physical displays.
- Add a built-in 24-color candidate set, configurable colors/labels/note and an
  optional palette reference row for gray4 and spectra6.
- Add fixed landscape/portrait grids, black/white overlay text chosen by WCAG
  contrast, safe areas, validated capture, clockwise rotation and atomic opaque
  RGB PNG output.
- Add offline source/container tests, opt-in browser checks and independent
  native amd64/arm64 verification and release workflows.
